Enterprise File Sharing System - 离线部署指南
==============================================

一、Docker 部署（推荐）

  前置条件：已安装 Docker Engine + Docker Compose

  1. 解压 file_manage-offline-package.zip 到一个目录（建议目录名就叫 file_manage），
     把 file_manage-images.tar 也放到同目录（放到 file_manage 里面）

  2. 导入镜像：
     docker load -i file_manage-images.tar

  3. 设置密钥（必须）：
     先生成一个随机密钥：openssl rand -base64 64
     然后创建 .env 文件（与 docker-compose.offline.yml 同目录），写入：
     JWT_SECRET=你生成的密钥

  4. 启动服务：
     docker-compose -f docker-compose.offline.yml up -d
     如果提示找不到 docker-compose 命令，改用：
     docker compose -f docker-compose.offline.yml up -d

  5. 访问系统：
     前端页面：http://localhost:8080
     健康检查：http://localhost:3000/api/health
     默认管理员：admin / Admin123!

二、非 Docker 部署

  前置条件：已安装 Node.js 18+ 和 Git

  直接运行一键部署脚本：

  Linux / macOS：
    chmod +x deploy.sh && ./deploy.sh

  Windows：
    双击 deploy.bat 或在终端运行 deploy.bat

  部署完成后访问：http://localhost:3000
  默认管理员：admin / Admin123!

三、常用管理命令

  Docker 环境：
    docker-compose -f docker-compose.offline.yml down        # 停止服务
    docker-compose -f docker-compose.offline.yml restart     # 重启服务
    docker-compose -f docker-compose.offline.yml logs -f     # 查看日志

  非 Docker 环境：
    pm2 status              # 查看运行状态
    pm2 logs file-share     # 查看日志
    pm2 restart file-share  # 重启服务
    pm2 stop file-share     # 停止服务

四、重要提醒

  1. 首次登录后请立即修改默认管理员密码（右上角菜单 → Change Password）
  2. 密码要求：至少 8 位，包含大小写字母和数字
  3. 数据备份：定期备份 database.sqlite 文件和 uploads 目录
